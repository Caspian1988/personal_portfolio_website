## ✨ Features

- 📱 **Fully Responsive Design:** Optimized for mobile, tablet, and desktop screens.
- ⚡ **Fast Performance:** Minimalistic design ensuring quick load times.
- 🛠️ **Project Showcase:** Highlights selected software projects with direct links to code repositories and live demos.
- 📬 **Contact Form & Links:** Simple ways for recruiters and collaborators to get in touch.
- 🎨 **Modern UI:** Styled with high-contrast, clean layout and intuitive navigation.

- **Frontend:** HTML5, CSS3, JavaScript (or React / Next.js)
- **Styling:** Custom CSS / Tailwind CSS / Bootstrap
- **Deployment:** Vercel / GitHub Pages / Netlify
